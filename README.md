
# XRan — Ransomware Detection

XRan is a ransomware detection project focused on identifying ransomware through behavioral analysis and deep learning techniques.

This repository contains the research, literature review, implementation, experiments, and documentation developed as part of the project.

## 📌 Project Overview

Ransomware is a type of malware that restricts access to files or systems, commonly by encrypting data and demanding a ransom.

Traditional signature-based detection methods can struggle with new and evolving ransomware samples. This project explores behavioral and deep learning-based approaches for detecting ransomware.

The project is being developed based on existing research in ransomware detection, with the goal of building an effective and explainable detection system.

## 🎯 Objectives

* Study existing ransomware detection techniques.
* Analyze ransomware behavior and characteristics.
* Explore dynamic and behavioral analysis for ransomware detection.
* Develop a deep learning-based ransomware detection system.
* Evaluate the performance of the proposed approach.
* Explore explainability techniques for understanding model predictions.
* Document the complete development and experimental process.
